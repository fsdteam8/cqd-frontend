# 🧼 CleanCo - Commercial Cleaning Service Platform

A modern, full-stack service marketplace built with the **MERN Stack** and **Next.js**, specifically designed for commercial and specialized cleaning industries.

## 🚀 Features
- **Industry-Specific Services:** Tailored cleaning solutions for GP Surgeries, Data Centres, Schools, and Fleet vehicles.
- **Seamless Booking Flow:** Multi-step booking process with real time availability.
- **Secure Payments:** Fully integrated with **Stripe** for one-time or recurring service payments.
- **Type-Safe Architecture:** Built with **TypeScript** for both frontend and backend to minimize runtime errors.
- **Performance Optimized:** Uses **Tanstack Query** for caching and synchronized data fetching.

## 🛠️ Technology Stack
- **Frontend:** Next.js, Tailwind CSS, Tanstack Query
- **Backend:** Express.js, Node.js
- **Database:** MongoDB
- **Auth:** Next Auth
- **Payments:** Stripe API

## 📂 Service Categories
Includes specialized cleaning for:
- **Medical:** GP Surgeries, Dental Clinics
- **Hospitality:** Pubs, Restaurants, Cinemas
- **Logistics:** Commercial Fleet, Marine & Boat Cleaning
- **Corporate:** Accountancy Offices, Showrooms
